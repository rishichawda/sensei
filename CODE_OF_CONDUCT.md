# Code of Conduct

The short version: don't be an ass.

The slightly longer version:

- Be kind.
- Argue with the idea, not the person.
- Assume good faith.
- No harassment, discrimination, personal attacks or unwelcome advances.
- Do not share other people's private information.
- Keep issues, pull requests and discussions about the project.
- Be the kind of contributor you would want to review a pull request from.

This applies wherever this project is discussed: issues, pull requests, and any other space where you speak for the project.

## When it goes wrong

To report something privately, use the contact form at <https://rishikc.com/contact/>.
